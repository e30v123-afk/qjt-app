# تطبيق قافلة الجزيرة

تحديث التطبيق المنشور `com.app.qjtcar1` ليعرض متجر **qjt.sa** داخل قشرة أصلية.

## ما الذي يضيفه التطبيق فوق الموقع؟
- شريط تنقّل سفلي أصلي (الرئيسية · الأقسام · السلة · المفضلة · حسابي) مع شارة عدد السلة وارتجاج لمسي.
- ورقة أقسام منزلقة للوصول السريع إلى البطاريات والزيوت والإطارات والمحسنات والخدمات والباقات.
- شاشة انقطاع اتصال بهوية المتجر مع إعادة محاولة تلقائية.
- سحب للتحديث.
- مشاركة المنتج عبر ورقة المشاركة الأصلية للنظام.
- تذكير محلي بالسلة المتروكة بعد ٦ ساعات.
- استبدال الصور المكسورة ببديل أنيق بدل المربّع الفارغ.
- فتح الروابط الخارجية في متصفّح النظام، وأرقام الهواتف في تطبيق الاتصال.
- شاشة إقلاع وأيقونة من شعار الشركة، وإيماءة الرجوع للخلف.

## البنية
| الملف | الدور |
|---|---|
| `www/shell.js` | القشرة — تُحقن في كل صفحة من qjt.sa داخل التطبيق فقط |
| `www/index.html` | صفحة الاحتياط عند تعذّر الوصول للمتجر |
| `ios-shell/QJTViewController.swift` | يحقن `shell.js` في الـ WebView قبل التحميل |
| `capacitor.config.json` | إعداد Capacitor (المصدر: https://qjt.sa) |
| `codemagic.yaml` | البناء السحابي والرفع إلى App Store |
| `make-assets.py` | توليد الأيقونة وشاشة الإقلاع من الشعار |
